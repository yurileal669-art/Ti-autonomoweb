SISTEMA

Sobre esta versão

Aplicação web para profissional autônomo de TI desenvolvida com HTML, CSS e JavaScript puro. Toda a lógica de negócio funciona no navegador.

Armazenamento: LocalStorage para dados estruturados e sessão local do navegador.

Funcionalidades: catálogo de serviços, orçamento, chamados, clientes, financeiro, feedback, notificações, relatórios e backup.

Importante: esta versão não processa pagamentos reais nem utiliza banco remoto. Para uso comercial multiusuário seria necessário backend.
